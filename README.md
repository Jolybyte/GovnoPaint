## ✨ Возможности

### 🖌️ Инструменты рисования
- **Базовые:** карандаш, ластик, линия, прямоугольник, эллипс, текст
- **Специальные:** заливка (Flood Fill на numpy), градиенты (линейный/радиальный/конический)
- **Кисти:** каллиграфия, фонтанная ручка, спрей, масляная кисть, маркер, акварель и др.

### 🎨 80+ Кастомных кистей
| Категория | Примеры |
|-----------|---------|
| **Экспериментальные** | Брызги, Свечение, Радуга, Неон, Лента |
| **Частицы** | Огонь, Дым, Пузыри, Искры |
| **Органические** | Лианы, Трава, Кораллы, Мех |
| **Геометрические** | Калейдоскоп, Молния, Микросхема, Соты, Фрактал |
| **Текстуры** | Холст, Ржавчина, Крошка, Кирпичи |
| **Космос** | Галактика, Созвездие, Аврора |
| **Магия** | Руны, Мана, Феникс |
| **Художественные** | Суми-э, Уголь, Дали, Эшер, Поллок |
| **Скетчинг** | Скетч-карандаш, Штриховка, Жестовая |
| **Комиксы** | Манга-тон, Комикс-инк, Скринтон |
| **Цифровая живопись** | Цифровое масло, Импасто, Мастихин |

### 📚 Слои (Photoshop-style)
- Неограниченное количество слоёв
- 12 режимов наложения (Multiply, Screen, Overlay, и др.)
- Регулировка прозрачности (0–100%)
- Видимость, блокировка, дублирование, объединение
- Drag & drop переупорядочивание
- Миниатюры слоёв

### 🛠️ Дополнительно
- **Undo/Redo** — до 100 шагов истории
- **Выделение:** прямоугольное и лассо
- **Трансформация:** поворот, масштабирование
- **Симметрия** — до 16 осей
- **Сетка** и привязка к ней
- **Линейка** для измерения расстояний
- **Зум** (Ctrl+Scroll) и настройка непрозрачности (Alt+Scroll)
- **Автосохранение** каждые 5 минут
- **Горячие клавиши** для всех основных действий

## 🚀 Установка

### Требования
- Python 3.10+
- PyQt6

### Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/govnopaint.git
cd govnopaint

# Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate   # Windows

# Установить зависимости
pip install -r requirements.txt

# Запустить
python main.py
```

### Установка как пакет

```bash
pip install -e .
govnopaint
```

## 🏗️ Архитектура

```
govnopaint/
├── main.py                 # Точка входа
├── src/
│   ├── app.py             # Основной виджет и приложение
│   ├── custom_brushes.py  # 80+ кастомных кистей
│   ├── flood_fill.py      # Оптимизированная заливка (numpy + scanline)
│   ├── layers.py          # Продвинутая система слоёв
│   └── styles.py          # Стили (Modern/Glassmorphism)
├── assets/                # Иконки и ресурсы
└── requirements.txt
```

### Ключевые классы

- **`PaintWidget`** — холст, обработка событий мыши/клавиатуры, рисование
- **`Layer`** — слой с изображением, режимом наложения и прозрачностью
- **`LayerPanel`** — UI-панель управления слоями
- **`PaintApp`** — главное окно с тулбаром, меню и статусбаром
- **`FloodFill`** — быстрая заливка (numpy-векторизация + scanline для больших изображений)

## 🤝 Вклад

Pull requests приветствуются! Для крупных изменений сначала откройте issue.

1. Fork репозитория
2. Создайте ветку (`git checkout -b feature/AmazingBrush`)
3. Commit (`git commit -m 'Add amazing brush'`)
4. Push (`git push origin feature/AmazingBrush`)
5. Откройте Pull Request

### Как добавить новую кисть

1. Откройте `src/custom_brushes.py`
2. Создайте класс с методом `draw`:

```python
class MyAwesomeBrush:
    @staticmethod
    def draw(painter, last_point, current_point, settings):
        color = settings.get('color', QColor(255, 0, 0))
        size = settings.get('size', 10)
        # ... логика рисования
```

3. Добавьте в `CUSTOM_BRUSHES` и `apply_brush`
4. Добавьте размер по умолчанию в `tool_brush_sizes` в `app.py`
